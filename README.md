# Credit Risk Prediction

End-to-end machine learning project for predicting credit repayment difficulties using Python and Google Cloud Platform (GCP).

The project aims to cover data exploration, preprocessing, model training and evaluation, and deployment of a prediction API using FastAPI, Docker, and Google Cloud Run.

**Status: In development.** Currently focused on data exploration and preprocessing.

## Data Information

| | |
|---|---|
| **Source** | Home Credit / Kaggle |
| **Link** | [Home Credit Default Risk](https://www.kaggle.com/competitions/home-credit-default-risk/data) |
| **Dataset** | `application_train.csv` |
| **Description** | Loan application data with applicant characteristics, financial information, and a binary target indicating repayment difficulties. |
| **Download Date** | 2026-11-17 |
